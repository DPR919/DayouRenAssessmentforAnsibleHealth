# DayouRenAssessmentforAnsibleHealth
## Brief Description
Technical Assessment for AnsibleHealth application

## Setup Instructions
Download the .ipynb file and upload it to your Google Colab environment.

## Required Dependencies
google-api-python-client google-auth-httplib2 google-auth-oauthlib

## How to run in Colab
After uploading the script to Colab, just hit Run All.

One cell will prompt the user to select a file. Another cell will prompt the user to authenticate their Google accounts.
